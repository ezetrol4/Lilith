# Security Policy

## Supported Versions

V1.x is currently supported.

## Reporting a Vulnerability

Please do **not** open a public issue containing exploitable security details.

Preferred reporting mechanism: GitHub private vulnerability reporting / Security Advisory, if enabled on this repository.

If private reporting is not available, please contact the maintainer privately through the contact method listed on the GitHub profile or repository, rather than through a public issue or discussion.

When reporting, please include:

- Affected version
- Affected component
- Reproduction steps
- Impact
- Suggested remediation, if known

## Scope

Security issues in Lilith itself are in scope for this policy.

Vulnerabilities discovered in third-party systems while *using* Lilith are not vulnerabilities in Lilith and must not be reported as Lilith security issues. Report those to the owner of the affected system instead.

## Responsible Disclosure

Please allow reasonable time for a fix before any public disclosure. We will do our best to acknowledge reports promptly and keep you informed of remediation progress.
